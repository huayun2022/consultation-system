# 云端版 · 使用与部署说明

`index.html` 是线上正式运行的前端源码，HTML / CSS / JavaScript 全部在这一个文件里；`vendor/index.global.js` 是云端 SDK 的本地副本。访问地址见仓库根目录 README 顶部信息卡。

界面按手机竖屏设计：单列表单、48px 以上触控按钮、16px 输入框避免 iOS 自动缩放，预约与账号列表改为卡片式，并适配全面屏底部安全区；宽屏下居中显示一栏，最大宽度 480px。

页面需要经托管域名打开。直接双击本地文件由于缺少网关与跨域配置，会连不上云端接口。

## 三个入口

- **来访者**：填写姓名、性别、年龄、手机号、预约日期（最早只能选明天）、咨询原因；提交后用「手机号 + 姓名」查询回复。
- **咨询师**：账号密码登录，分「待回复 / 已回复」两栏填写回复，可修改自己的密码。
- **管理员**：查看统计、导出 JSON、清空数据、新增或停用账号、重置他人密码、修改自己密码。

## 账号

账号在数据库中建立，初始密码通过私下渠道分发，不写入本仓库。连续输错 5 次会锁定 15 分钟，登录状态 12 小时有效，用完请点「安全退出」。

## 配置

`index.html` 顶部的 `publicConfig` 必须与托管应用一致：

| 字段 | 说明 |
| --- | --- |
| `endpoint` | 应用公网域名 |
| `oauthRelayBaseUrl` | SDK OAuth 中继地址 |
| `publishableKey` | 公开客户端密钥，前端可见；数据读取由数据库 RLS 与服务端函数控制 |

`RPC_OF` 把前端动作映射到数据库函数，名称需与 `server.md` 一致。SDK 优先从 CDN 加载，失败时回退到 `vendor/index.global.js`；托管网关要求子请求也带 `sharecode`，回退路径已自动拼接。

## 重新发布

修改后用托管环境重新发布，并复用同一个应用 ID，否则 `endpoint` 与密钥不匹配。发布后按这个顺序验证：匿名提交一条测试预约 → 咨询师登录能看到并回复 → 来访者凭手机号加姓名查到回复 → 管理员导出后清掉测试数据。

## 注意

导出文件含来访者手机号和咨询原因，请妥善保管；「清空所有预约」不可恢复，操作前先导出备份。
